# EDITH Studio：内核骨架

```text
main → studio → engine
                  ├─ models
                  ├─ tools
                  └─ session
```

```text
HTTP JSON → RunInput → Engine.Run → StreamEvent → SSE

Engine.Run 内部：Runner.Run → frameworkEventCh → 现场读取框架字段
```

- `main`：启动进程、监听 HTTP、处理退出。
- `studio`：HTTP/SSE；不读取框架 Event 字段。
- `engine`：组装并运行 Agent；在 `Run` 循环中直接读取框架事件。
- `models`：读取自己的用户级 `models.yaml`，创建模型实例。
- `tools`、`session`：各自拥有自己的初始化与生命周期。

没有总配置模块，也没有工具审批模块。
