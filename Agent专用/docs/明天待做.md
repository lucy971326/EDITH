# Artifact：结构化文件展示

目标：Agent 写出真实文件后，由后端确认并告诉前端如何展示；不依赖模型输出 DSL。

```text
Agent 写 Workspace 文件
→ 后端确认文件存在
→ 返回 Artifact Metadata
→ 前端按 kind 展示
```

第一版只做静态网页：

```json
{
  "kind": "web",
  "title": "番茄钟",
  "entry_path": "index.html"
}
```

- Agent：用现有文件工具写 `index.html`、`style.css`、`app.js`
- 后端：按 `userID + sessionID` 找 Workspace，校验并读取预览文件
- 前端：有 Artifact 时显示「作品预览」按钮；点击后在右侧 iframe 展示
- Local / E2B：都经由 `ExecBackend.ReadFile`，预览逻辑不关心实际后端

安全边界：拒绝 `..` / 绝对路径；iframe 使用 `sandbox="allow-scripts"`。
