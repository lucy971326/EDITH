# trpc-agent-go 执行流程时序图

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant Runner
    participant SessionService
    participant Agent as Agent (LLMAgent)
    participant LLMFlow as LLM Flow
    participant Model
    participant Tool

    rect rgb(230, 245, 255)
        Note over User,Tool: 阶段1：用户发起查询
        User->>Runner: 发送查询 "法国的首都是什么？"
        Runner->>SessionService: GetSession(ctx, sessionKey)
        SessionService-->>Runner: 返回会话（或创建新会话）
        Runner->>Runner: 生成 invocationID
        Runner->>Runner: 创建 userEvent
        Runner->>SessionService: AppendEvent()
        Runner->>Agent: agent.Run(ctx, invocation)
        Agent->>Agent: 设置调用上下文<br/>运行 Agent 前置回调
        Agent->>LLMFlow: flow.Run(ctx, invocation)
        LLMFlow->>LLMFlow: 准备系统提示词和工具
        LLMFlow->>Model: model.GenerateContent(ctx, request)
        Model-->>LLMFlow: 返回 FunctionCall
        LLMFlow->>LLMFlow: 创建 FunctionCall 事件<br/>RequiresCompletion = true
        LLMFlow-->>Runner: yield Event(FunctionCall)
        Runner->>SessionService: AppendEvent 到会话
        Runner-->>User: yield Event(FunctionCall)
        Note over User: 用户收到工具调用事件
    end

    rect rgb(255, 245, 230)
        Note over User,Tool: 阶段2：执行工具
        Runner->>Agent: 内部：EventCompletionCh <- CompletionID
        Runner->>Agent: 恢复执行（内部）
        Agent->>LLMFlow: 恢复流程执行
        LLMFlow->>Tool: tool.Call(ctx, toolArgs)
        Tool-->>LLMFlow: {"result": "Paris"}
        LLMFlow->>LLMFlow: 创建 FunctionResponse 事件<br/>RequiresCompletion = true
        LLMFlow-->>Runner: yield Event(FunctionResponse)
        Runner->>SessionService: AppendEvent 到会话
        Runner-->>User: yield Event(FunctionResponse)
        Note over User: 用户收到工具响应事件
    end

    rect rgb(230, 255, 230)
        Note over User,Tool: 阶段3：返回最终答案
        Runner->>Agent: 内部：EventCompletionCh <- CompletionID
        Runner->>Agent: 恢复执行（内部）
        Agent->>LLMFlow: 恢复流程执行
        LLMFlow->>Model: 发送工具结果以获取最终答案
        Model-->>LLMFlow: "法国的首都是巴黎。"
        LLMFlow->>LLMFlow: 创建最终文本事件
        LLMFlow-->>Runner: yield Event(FinalText)
        Runner->>SessionService: AppendEvent 到会话
        Runner-->>User: yield Event(FinalText)
        Note over User: 用户收到最终答案事件
    end

    rect rgb(245, 230, 255)
        Note over User,Tool: 阶段4：完成
        Runner->>Runner: 生成器耗尽<br/>发出 Runner 完成事件
        Runner->>Runner: 创建 RunnerCompletionEvent<br/>ObjectTypeRunnerCompletion
        Runner->>SessionService: AppendEvent 到会话
        Runner-->>User: 返回最终结果
    end
```

## 流程说明

| 阶段 | 动作 | 关键点 |
|------|------|--------|
| **阶段1** | 用户发起查询 | 加载会话 → 调用 LLM → 返回工具调用 |
| **阶段2** | 执行工具 | 执行工具 → 返回工具结果 |
| **阶段3** | 返回最终答案 | 发送工具结果 → LLM 生成最终答案 |
| **阶段4** | 完成 | 保存完成事件 → 返回最终结果 |

## 关键概念

| 概念 | 说明 |
|------|------|
| **invocationID** | 唯一标识本次调用 |
| **EventCompletionCh** | 用于恢复执行的通道 |
| **RequiresCompletion** | 标记需要继续执行 |
| **yield** | 产出事件给用户 |
| **AppendEvent** | 保存事件到会话 |
