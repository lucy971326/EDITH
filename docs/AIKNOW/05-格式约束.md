# EDITH 前后端交互格式

> 新增或修改浏览器 ↔ BFF ↔ Go 的格式时，同时更新本文档及对应的 Go / TypeScript 类型。

## 请求

浏览器 → Next BFF：

```ts
type ChatRequest = {
  sessionId: string;
  message: string;
  modelId: string;
  reasoningOptionId?: string;
};
```

Next BFF → Go Runtime：

```ts
type AgentRunRequest = {
  userId: string;
  sessionId: string;
  message: string;
  modelId: string;
  reasoningOptionId?: string;
};
```

`userId` 只能由 BFF 从 Clerk 获取，浏览器不传。

用户设置，浏览器 → Next BFF：

```ts
type SaveUserSettingsRequest = {
  personality: string;
  providers: { providerId: string; apiKey?: string }[];
};

type UserSettingsResponse = {
  personality: string;
  providers: { providerId: string; hasApiKey: boolean }[];
};
```

```text
GET /api/settings → UserSettingsResponse
PUT /api/settings ← SaveUserSettingsRequest → UserSettingsResponse
```

`apiKey` 只能浏览器 → 服务端；读取接口永远不返回明文 Key。

## MCP 服务

```ts
type MCPTransport = "streamable" | "sse";

type MCPHeaderState = {
  name: string;
  hasValue: boolean;
};

type MCPServer = {
  id: string;
  name: string;
  url: string;
  transport: MCPTransport;
  enabled: boolean;
  headers: MCPHeaderState[];
};

type CreateMCPServerRequest = {
  name: string;
  url: string;
  transport: MCPTransport;
  enabled: boolean;
  headers: { name: string; value: string }[];
};

type UpdateMCPServerRequest = {
  name: string;
  url: string;
  transport: MCPTransport;
  enabled: boolean;
  headers: { name: string; value?: string }[];
};
```

```text
GET    /api/mcp-servers → { servers: MCPServer[] }
POST   /api/mcp-servers ← CreateMCPServerRequest → MCPServer
PUT    /api/mcp-servers/{serverId} ← UpdateMCPServerRequest → MCPServer
DELETE /api/mcp-servers/{serverId} → 204
```

Header 值只允许写入；读取接口仅返回 `hasValue`。

## 模型目录

```ts
GET /api/models

type ModelInfo = {
  id: string;
  providerId: string;
  name: string;
  reasoningOptions: { id: string; name: string }[];
};

type ModelCatalogResponse = {
  providers: { id: string; name: string }[];
  models: ModelInfo[];
};
```

## 历史与页面状态：Timeline

```ts
type Conversation = {
  id: string;
  title: string; // 第一条用户消息的前 18 个字符
  updatedAt: string;
};

type ConversationListResponse = {
  conversations: Conversation[];
};

type ConversationResponse = {
  timeline: Timeline;
};
```

```text
GET /api/conversations → ConversationListResponse
GET /api/conversations/{sessionId} → ConversationResponse
```

```ts
type Timeline = {
  blocks: TimelineBlock[];
};

type TimelineBlock = UserBlock | AssistantBlock | ErrorBlock;

type UserBlock = {
  type: "user";
  id: string;
  content: string;
  createdAt: string;
};

type AssistantBlock = {
  type: "assistant";
  id: string;
  createdAt: string;
  blocks: AssistantContentBlock[];
};

type ErrorBlock = {
  type: "error";
  id: string;
  message: string;
  createdAt: string;
};

type AssistantContentBlock = ReasoningBlock | TextBlock | ToolBlock;

type ReasoningBlock = {
  type: "reasoning";
  id: string;
  content: string;
};

type TextBlock = {
  type: "text";
  id: string;
  content: string;
};

type ToolBlock = {
  type: "tool";
  id: string;
  toolName: string;
  arguments: string;
  status: "running" | "completed" | "failed";
  result?: string;
};
```

`createdAt` 是 RFC3339 字符串。

## 实时 SSE

每个 `data:` 是下列 JSON 之一：

```ts
type ChatStreamEvent =
  | AssistantStartedEvent
  | ContentDeltaEvent
  | ToolStartedEvent
  | ToolFinishedEvent
  | ErrorEvent
  | DoneEvent;

type AssistantStartedEvent = {
  type: "assistant.started";
  assistant: AssistantBlock;
};

type ContentDeltaEvent = {
  type: "assistant.content.delta";
  assistantId: string;
  blockId: string;
  blockType: "reasoning" | "text";
  delta: string;
};

type ToolStartedEvent = {
  type: "tool.started";
  assistantId: string;
  tool: ToolBlock;
};

type ToolFinishedEvent = {
  type: "tool.finished";
  assistantId: string;
  toolCallId: string;
  status: "completed" | "failed";
  result?: string;
};

type ErrorEvent = {
  type: "error";
  error: ErrorBlock;
};

type DoneEvent = {
  type: "done";
  requestId: string;
  usage?: Usage;
};

type Usage = {
  promptTokens: number;
  completionTokens: number;
  totalTokens: number;
};
```

## 工具配对

```text
ToolBlock.id = framework ToolCall.ID = tool.finished.toolCallId
```

收到 `tool.started` 创建卡片；收到 `tool.finished` 更新同一张卡片。不得按工具名配对。
