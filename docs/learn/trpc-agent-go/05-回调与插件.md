# 05 - 回调（Callbacks）与插件（Plugins）

> Hook 体系是框架的"插入点"。Callbacks = Agent 级局部，Plugins = Runner 级全局。

---

## 1. 心智模型

> **Callbacks = Agent 执行流程的"钩子点"，让你在流程关键节点插入自定义逻辑。**
> 回调 = 函数切片（不是接口），结构体存储它们。三类回调遵循同一模式。

### Callback vs Plugin

| 维度 | Callback（回调） | Plugin（插件） |
|---|---|---|
| 作用域 | 某个 Agent（局部） | 整个 Runner（全局） |
| 注册方式 | `WithAgentCallbacks(...)` | `runner.WithPlugins(...)` |
| 适用 | 某个 Agent 的特殊行为 | 横切关注点（日志/安全/审计/全局指令） |
| 复用 | 一般不复用 | 一次注册，所有 Agent 自动生效 |

**关系**：Plugin 内部就是一组 Callbacks 的"打包"，按 Runner 级 → Run 级 → Agent 级顺序执行。

---

## 2. 三类回调总览

| 回调类型 | 触发时机 | 可拦截点 | 典型用途 |
|---|---|---|---|
| **ModelCallbacks** | 模型推理前后 | Before 可跳过模型调用；After 可替换响应 | 输入审计、缓存 mock、输出格式化 |
| **ToolCallbacks** | 工具执行前后 | Before 可 Mock/改参数；After 可替换结果；SkipSummarization | 参数清洗、结果重写、长任务跳过总结 |
| **AgentCallbacks** | Agent 执行前后 | Before 可中止；After 可替换输出 | 计时、入口校验、出口处理 |

---

## 3. 统一结构体模式

所有 Callbacks 都是**结构体**（不是接口），遵循同一模式：

```go
type Callbacks struct {
    BeforeFunc     []BeforeFunc      // 函数切片
    AfterFunc      []AfterFunc
    continueOnError    bool
    continueOnResponse bool
}
```

**控制选项**：
- 默认：遇到第一个错误或非空结果就停止
- `WithContinueOnError(true)`：错误继续，保留第一个错误
- `WithContinueOnResponse(true)`：非空结果继续，使用最后一个结果

## 4. AgentCallbacks

### 4.1 注册

```go
callbacks := agent.NewCallbacks()

callbacks.RegisterBeforeAgent(func(ctx, args *agent.BeforeAgentArgs) (*agent.BeforeAgentResult, error) {
    // args.Invocation.AgentName
    // args.Invocation.Session
    if !isAllowed(args.Invocation.Message) {
        return &agent.BeforeAgentResult{
            CustomResponse: &model.Response{
                Choices: []model.Choice{{
                    Message: model.NewAssistantMessage("请求被拒绝"),
                }},
                Done: true,
            },
        }, nil  // ← 非空 CustomResponse 短路
    }
    return nil, nil
})

callbacks.RegisterAfterAgent(func(ctx, args *agent.AfterAgentArgs) (*agent.AfterAgentResult, error) {
    log.Printf("Agent %s done, err=%v", args.Invocation.AgentName, args.Error)
    return nil, nil
})

agent := llmagent.New("assistant",
    llmagent.WithAgentCallbacks(callbacks),
)
```

### 4.2 参数 / 结果

```go
type BeforeAgentArgs struct {
    Invocation *Invocation
}
type BeforeAgentResult struct {
    Context        context.Context
    CustomResponse *model.Response  // 非空跳过执行
}

type AfterAgentArgs struct {
    Invocation        *Invocation
    FullResponseEvent *event.Event
    Error             error
}
type AfterAgentResult struct {
    Context        context.Context
    CustomResponse *model.Response  // 非空替换原响应
}
```

### 4.3 在回调里停止 Agent

```go
import "trpc.group/trpc-go/trpc-agent-go/agent"

callbacks.RegisterBeforeAgent(func(ctx, args) (*agent.BeforeAgentResult, error) {
    if shouldStop(args.Invocation) {
        return nil, agent.NewStopError("策略不允许")
    }
    return nil, nil
})
```

详见 `callbacks.md` 的 `在回调中停止 agent` 章节。

## 5. ModelCallbacks

```go
modelCallbacks := model.NewCallbacks()

// Before：可跳过 LLM 调用
modelCallbacks.RegisterBeforeModel(func(ctx, args *model.BeforeModelArgs) (*model.BeforeModelResult, error) {
    // args.Request.Messages
    if needsCache(args.Request) {
        return &model.BeforeModelResult{
            CustomResponse: &model.Response{ /* 缓存命中 */ },
        }, nil
    }
    return nil, nil
})

// After：可替换响应
modelCallbacks.RegisterAfterModel(func(ctx, args *model.AfterModelArgs) (*model.AfterModelResult, error) {
    // args.Response
    return nil, nil
})

agent := llmagent.New("assistant",
    llmagent.WithModelCallbacks(modelCallbacks),
)
```

## 6. ToolCallbacks

### 6.1 注册

```go
toolCallbacks := tool.NewCallbacks()

toolCallbacks.RegisterBeforeTool(func(ctx, args *tool.BeforeToolArgs) (*tool.BeforeToolResult, error) {
    // args.ToolCallID / ToolName / Arguments ([]byte)
    if args.ToolName == "dangerous_tool" {
        return &tool.BeforeToolResult{
            CustomResult: map[string]any{"error": "denied"},
        }, nil
    }
    return nil, nil
})

toolCallbacks.RegisterAfterTool(func(ctx, args *tool.AfterToolArgs) (*tool.AfterToolResult, error) {
    // args.Result / Error
    return &tool.AfterToolResult{
        SkipSummarization: true,  // 跳过总结 LLM 调用
    }, nil
})
```

### 6.2 参数 / 结果

```go
type BeforeToolArgs struct {
    ToolCallID  string
    ToolName    string
    Declaration *tool.Declaration
    Arguments   []byte  // 可修改
}
type BeforeToolResult struct {
    Context           context.Context
    CustomResult      any    // 非空跳过执行
    ModifiedArguments []byte // 修改后的参数
}

type AfterToolArgs struct {
    ToolCallID  string
    ToolName    string
    Declaration *tool.Declaration
    Arguments   []byte  // before 回调后的最终参数
    Result      any
    Error       error
}
type AfterToolResult struct {
    Context            context.Context
    CustomResult       any  // 非空替换原结果
    SkipSummarization  bool
}
```

## 7. Invocation State（在回调间共享数据）

```go
// BeforeAgent 存
args.Invocation.SetState("agent:start_time", time.Now())

// AfterAgent 取
if t, ok := args.Invocation.GetState("agent:start_time"); ok {
    duration := time.Since(t.(time.Time))
}

// 清理
args.Invocation.DeleteState("agent:start_time")
```

**特点**：Invocation 级作用域、线程安全（RWMutex）、懒初始化。

**建议命名前缀**：
- Agent 回调：`agent:xxx`
- Model 回调：`model:xxx`
- Tool 回调：`tool:<toolName>:<toolCallID>:xxx`

完整示例见 `callbacks.md` 的 `Invocation State：在回调间共享状态` 章节。

## 8. Plugins（插件）

### 9.1 心智模型

> **Plugin = Callbacks 的"物业公司"，统一管理多个 Hook 点的回调注册与全局生效。**

### 9.2 接口

```go
type Plugin interface {
    Name() string             // 插件名，同一 Runner 内唯一
    Register(r *Registry)     // 在这里注册回调到 Hook 点
}

// 可选：资源释放
type Closer interface {
    Close(ctx context.Context) error
}
```

### 9.3 写一个自定义插件

```go
import "trpc.group/trpc-go/trpc-agent-go/plugin"

type MyPlugin struct{}

func (p *MyPlugin) Name() string { return "my-plugin" }

func (p *MyPlugin) Register(reg *plugin.Registry) {
    reg.BeforeModel(func(ctx, args *model.BeforeModelArgs) (*model.BeforeModelResult, error) {
        log.Printf("BeforeModel: %v", args.Request.Messages)
        return nil, nil
    })
    reg.OnEvent(func(ctx, invocation *agent.Invocation, ev *event.Event) (*event.Event, error) {
        // 改写事件或返回替代品
        return ev, nil
    })
}

// 注册到 Runner
r := runner.NewRunner("app", agent,
    runner.WithPlugins(&MyPlugin{}),
)
```

### 9.4 Registry 可注册的方法

- `BeforeAgent(cb)` / `AfterAgent(cb)`
- `BeforeModel(cb)` / `AfterModel(cb)`
- `BeforeTool(cb)` / `AfterTool(cb)`
- `OnEvent(hook)` — 拦截每个事件
- `AfterToolMessages(hook)`

### 9.5 单次 Run 插件

```go
r.Run(ctx, userID, sessionID, msg,
    plugin.WithPlugins(&RequestPlugin{}),
)
```

Run 级插件排在 Runner 级插件之后执行，只对本次 Run 生效。

### 9.6 OnEvent 的特殊性

Runner 发出**每个事件**时都会调用，可原地修改或返回替代品。

```go
reg.OnEvent(func(ctx, invocation, ev *event.Event) (*event.Event, error) {
    if shouldTag(ev) {
        ev.Tag = "my-tag"
    }
    return ev, nil
})
```

**OnEvent 回调返回 error 框架只记日志，不退整个请求。**

## 9. 执行顺序

```
Runner 级插件 → Run 级插件 → Agent 回调
（全局，持久）    （本次运行）   （局部，Agent 专属）
```

每类 Hook 点：
```
Plugin[Runner].BeforeModel → Plugin[Run-1].BeforeModel → ... → Agent.BeforeModel
Plugin[Runner].OnEvent     → Plugin[Run-1].OnEvent     → ... → (写入 Session)
```

**双层回调**：Agent 和 Tool 都有两层（Plugin 层先，用户注册的 LLMAgent 层后）。

**Propagation**：`Invocation.Clone()/View()` 共享同一个 `PluginManager` 指针，子 Agent、AgentTool、transfer 都自动继承父级插件。

## 10. 内置插件

| 插件 | Hook 点 | 功能 |
|---|---|---|
| `Logging` | Before/After Agent/Model/Tool | 日志 + 性能 |
| `DebugLog` | 所有 + OnEvent | 单行 JSON debug 输出 |
| `GlobalInstruction` | BeforeModel | 每次请求追加 system message |
| `ToolCallID` | AfterModel | 改写 ToolCall.ID 确保唯一 |
| `Identity` | BeforeAgent + BeforeTool | 用户身份透传工具 context |
| `MessageMerger` | BeforeModel | 合并连续同 role 消息 |
| `ErrorMessage` | OnEvent | 改写错误事件文案 |
| `Guardrail` | BeforeModel + BeforeTool | 审批 / 提示注入 / 危险意图检测 |

## 12. 踩坑提醒

| 坑 | 解法 |
|---|---|
| 回调没生效 | 确认注册的是结构化 API（`RegisterBeforeAgent`），不是 deprecated 旧版 |
| Before 回调的 CustomResponse 不生效 | 确保返回的是 `*model.Response` 而非 nil |
| OnEvent 改不动 | 直接改 ev 字段，返回 ev；或返回新 ev |
| Plugin Name 冲突 | 同一 Runner 内 Name 必须唯一 |
| Run 级插件 Close 没调用 | Run 级插件由调用方管理，Runner 不 Close |
| 在回调里启动 goroutine 不受 ctx 控制 | 用 `<-ctx.Done()` 监听 |
| 回调里 `args.Invocation.SetState` panic | 旧版本才 panic，新版线程安全 |
