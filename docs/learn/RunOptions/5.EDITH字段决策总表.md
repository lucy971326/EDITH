# EDITH RunOptions 字段决策总表

> 全部 RunOptions 字段在 EDITH 的用法决策——一张表看完。

---

## 决策分类

| 状态 | 含义 |
|---|---|
| ✅ **核心** | EDITH 当前实现，每个 Run 必用 |
| ✅ **场景** | EDITH 当前在特定场景用 |
| ⏳ **未来** | 真实需求出现时启用 |
| ❌ **不用** | EDITH 设计决定不引入 |

---

## 字段总表

### 1. 身份与生命周期

| 字段 | 状态 | 用途 |
|---|---|---|
| `RequestID` | ✅ 核心 | 链路追踪，uuid 生成 |
| `DetachedCancel` | ⏳ 未来 | HTTP 立刻返回 + 后台跑（EDITH 现在不需要） |
| `MaxRunDuration` | ⏳ 未来 | VIP 用户超时区分（EDITH 现在没分级） |
| `Resume` | ❌ 不用 | 中断续跑——EDITH 现在用 HTTP ctx 自动取消 |

### 2. 多用户隔离

| 字段 | 状态 | 用途 |
|---|---|---|
| `AppName` | ❌ 不用 | appName 固定为 "edith" |
| `EventFilterKey` | ❌ 不用 | EDITH 没有多租户隔离需求 |
| `RuntimeState` | ⏳ 未来 | 业务级 KV 透传到 invocation（EDITH 现在不需要） |

### 3. 模型分流

| 字段 | 状态 | 用途 |
|---|---|---|
| `Model` | ❌ 不用 | EDITH 用 ModelName 按名字查 |
| **`ModelName`** | ✅ 核心 | 用户选模型 |
| `ModelSelector` | ⏳ 未来 | 每次 LLM 调用前动态选（EDITH 不需要） |
| `ModelContextWindow` | ❌ 不用 | 模型实例已经配置 |
| `ModelRequestExtraFields` | ❌ 不用 | provider 兼容由 model 工厂处理 |
| **`ModelRequestHeaders`** | ✅ **核心** | **多租户关键——每个用户自己的 API key** |
| `Stream` | ✅ 场景 | 渠道默认（web=true, telegram=false） |

### 4. Prompt 动态化

| 字段 | 状态 | 用途 |
|---|---|---|
| **`GlobalInstruction`** | ✅ 核心 | L1 身份 + L2 性格（EDITH 重新定义） |
| **`Instruction`** | ✅ 核心 | L3 系统 skills + L4 用户 skills（EDITH 重新定义） |
| `InjectedContextMessages` | ❌ 不用 | 缓存杀手——EDITH 用 Instruction 替代 |
| `LateContextMessages` | ⏳ 未来 | EDITH 暂用 Instruction 统一管 skills |
| `UserMessageRewriter` | ⏳ 未来 | 1→N 展开场景 |

### 5. 工具隔离

| 字段 | 状态 | 用途 |
|---|---|---|
| `ToolFilter` | ❌ 不用 | EDITH 没有角色概念 |
| **`AdditionalTools`** | ✅ 核心 | **每次 Run 追加用户级 MCP 工具** |
| `ExternalTools` | ❌ 不用 | EDITH 没有前端工具概念 |
| `ToolExecutionFilter` | ⏳ 未来 | 审计类需求 |
| `ToolPermissionPolicy` | ⏳ 未来 | 危险操作审批 |

### 6. 执行环境隔离

| 字段 | 状态 | 用途 |
|---|---|---|
| `CodeExecutor` | ❌ 不用 | EDITH 自己造 sandbox（sandbox.BackendProvider） |
| `WorkspaceExecGuidance` | ❌ 不用 | EDITH 自己造 Workspace |
| `AvailableSkillsRenderer` | ❌ 不用 | EDITH 自己造 Skills |

### 7. 数据输入

| 字段 | 状态 | 用途 |
|---|---|---|
| `Messages` | ❌ 不用 | EDITH 用 SessionService 自动管历史 |
| `KnowledgeFilter` | ⏳ 未来 | 知识库——预留位置 |
| `KnowledgeConditionedFilter` | ⏳ 未来 | 高级用法 |

### 8. 流控与可观测

| 字段 | 状态 | 用途 |
|---|---|---|
| `StreamModeEnabled` / `StreamModes` | ❌ 不用 | EDITH 不需要事件过滤 |
| `PersistInterruptedAssistant` | ⏳ 未来 | "从断点继续"场景 |
| `GraphEmitFinalModelResponses` | ❌ 不用 | EDITH 不用 GraphAgent |
| `GraphTerminalMessagesOnly` | ❌ 不用 | EDITH 不用 GraphAgent |
| `DisableTracing` | ⏳ 未来 | 性能优化 |
| `DisableResponseUsageTracking` | ⏳ 未来 | 性能优化 |
| `DisableModelExecutionEvents` | ⏳ 未来 | 性能优化 |
| `LatencyDiagnosticsEnabled` | ⏳ 未来 | 调试 |
| `ExecutionTraceEnabled` | ⏳ 未来 | 调试 |
| `MaxLLMCalls` / `MaxToolIterations` | ⏳ 未来 | Invocation 安全限制 |
| `ToolCallArgumentsJSONRepairEnabled` | ⏳ 未来 | 自动修复 JSON |
| `ToolCallTextRepairEnabled` | ⏳ 未来 | 修复文本型工具调用 |
| `Plugins` (Run 级) | ⏳ 未来 | Run 级横切规则 |

## 当前实现的核心字段（7 个）

```
✅ RequestID                # 链路追踪
✅ WithStream               # 渠道默认（web/telegram）
✅ WithModelName            # 用户选模型
✅ WithModelRequestHeaders  # 多租户 API key
✅ WithGlobalInstruction    # L1 身份 + L2 性格
✅ WithInstruction          # L3 系统 skills + L4 用户 skills
✅ WithAdditionalTools      # 用户级 MCP 工具
```

**7 个 RunOptions 字段 + 1 个 Runner 长期骨架 = EDITH 当前的服务端 Agent 实现**。

---

## 不用字段的归类

**EDITH 自己造的（替代框架字段）**：

| 框架字段 | EDITH 自己的实现 |
|---|---|
| `CodeExecutor` | `sandbox.BackendProvider`（Local / E2B） |
| `WorkspaceExecGuidance` | EDITH 的 Workspace 系统 |
| `AvailableSkillsRenderer` | EDITH 的 Skills 系统 |
| `skill_load` 等框架工具 | 不引入 |

**当前没需求的**：

| 字段 | 原因 |
|---|---|
| `AppName` | appName 固定 |
| `Model` | 用 ModelName |
| `ModelContextWindow` | 模型实例配置 |
| `ModelRequestExtraFields` | provider 兼容已处理 |
| `Messages` | EDITH 用 SessionService |
| `StreamModes` | 不需要事件过滤 |
| `GraphEmitFinalModelResponses` 等 | 不用 GraphAgent |

**缓存杀手（EDITH 设计决定不用）**：

| 字段 | 原因 |
|---|---|
| `InjectedContextMessages` | 会切断 history cache |

---

## 一句话

> **7 个核心 RunOptions 字段承担 EDITH 当前服务端 Agent 全部能力**。
>
> **其他字段按"真实需求驱动"原则按需启用**——框架是为通用场景设计，EDITH 只挑自己需要的。
