# EDITH Prompt 层级与字段映射

> EDITH 的 prompt 管理方案——把 6 个层次映射到 RunOptions 字段。

---

## 核心结论

| 字段 | 内容 | 修改者 |
|---|---|---|
| **GlobalInstruction** | L1 身份 + L2 性格 | 开发者 |
| **Instruction** | L3 系统 skills + L4 用户 skills | 开发者（系统）+ 用户（自己的） |
| **Runner.Run() message** | L5 当轮用户消息 | 用户 |
| **SessionService 自动** | L6 历史 | 框架自动 |

---

## 为什么这么映射

**字段语义匹配**：

| 字段 | 语义 | 适合放什么 |
|---|---|---|
| GlobalInstruction | "系统前言，最稳定" | **身份 + 性格**（我是谁） |
| Instruction | "任务级补充" | **Skills 摘要**（我能做什么） |

**关键洞察**：Instruction **不只是"性格"**——它是"任务级补充内容"。Skills 摘要是"任务级"，所以放 Instruction 更合适。

---

## 最终 System 块顺序

```
[GlobalInstruction]  L1 身份 + L2 性格    ← 身份 → 性格
[Instruction]        L3 + L4 skills 摘要  ← 工具
```

**顺序逻辑**：**基础在前（身份/性格），动态在后（skills）**。

---

## EDITH 6 层 prompt 模型

```
┌──────────────────────────────────────────────────────────────┐
│                     EDITH Prompt Stack                        │
├──────────────────────────────────────────────────────────────┤
│                                                                │
│  L1 开发者全局身份（稳定）                                     │
│     ├─ 来源: prompts/edith.md                                 │
│     ├─ 注入: WithGlobalInstruction                            │
│     └─ 状态: ✅                                                │
│                                                                │
│  L2 用户 Agent 性格（稳定）                                    │
│     ├─ 来源: 用户配置（未来）                                  │
│     ├─ 注入: 拼到 GlobalInstruction                           │
│     └─ 状态: ⏳ 未来                                           │
│                                                                │
│  L3 系统 Skills 摘要（半稳定）                                 │
│     ├─ 来源: skills/system/*.md (SKILL.md frontmatter)        │
│     ├─ 注入: WithInstruction                                  │
│     └─ 状态: ✅ 启动时读                                       │
│                                                                │
│  L4 用户 Skills 摘要（每轮变）                                  │
│     ├─ 来源: user_skills/{hash}/*.md                          │
│     ├─ 注入: WithInstruction                                  │
│     └─ 状态: ✅ 每次 Run 读                                    │
│                                                                │
│  L5 当轮用户消息                                                │
│     ├─ 来源: HTTP / Telegram                                  │
│     ├─ 注入: Runner.Run() message 参数                        │
│     └─ 状态: ✅                                                │
│                                                                │
│  L6 Session History                                            │
│     ├─ 来源: SQLite session_events                             │
│     ├─ 注入: 框架自动                                         │
│     └─ 状态: ✅                                                │
│                                                                │
└──────────────────────────────────────────────────────────────┘
```

---

## 注入流程

```
启动时（main.go）:
  ┌─────────────────────────────────────────────────────┐
  │ L1 = 读 prompts/edith.md                            │
  │ L2 = 读用户默认 personality（未来）                  │
  │ GlobalInstruction = L1 + L2                         │
  │                                                    │
  │ LLMAgent.WithGlobalInstruction(...)                 │
  │ LLMAgent.Instruction 暂不设（每次 Run 动态传）       │
  └─────────────────────────────────────────────────────┘

每次 Run (Handler):
  ┌─────────────────────────────────────────────────────┐
  │ 1. 读 L3 skills/system/*.md  → systemOverview       │
  │ 2. 读 L4 user_skills/{hash}/*.md → userOverview     │
  │ 3. 组装 RunOptions:                                 │
  │    - WithRequestID(reqID)                           │
  │    - WithInstruction(systemOverview + userOverview) │
  │ 4. Runner.Run(ctx, userID, sessionID, msg, opts...) │
  │ 5. 框架自动加载 L6 Session History                  │
  └─────────────────────────────────────────────────────┘
```

---

## EDITH 不用的层（明确）

| 字段 | 为什么不用 |
|---|---|
| `WithInjectedContextMessages` | 缓存杀手——会切断 history cache |
| `WithLateContextMessages` | EDITH 用 Instruction 统一管理 skills |
| `WithFewShot` | Skills 摘要已覆盖 |
| `WithSkills(repo)` | **EDITH 自己造 Skills** |

---

## 一句话

> **GlobalInstruction = L1 身份 + L2 性格**（稳定前缀）。
>
> **Instruction = L3 系统 skills + L4 用户 skills**（任务级补充）。
>
> **顺序：身份 → 性格 → 工具 → 历史 → 当前**。
